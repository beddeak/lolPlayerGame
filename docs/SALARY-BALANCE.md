# 연봉 밸런스

게임 테스트용 자체 밸런스이며 실제 선수의 공개/비공개 연봉을 재현하는 자료가 아니다.
금액 단위는 **만원/년**. 10,000 = 1억 원. 이적료와는 별도다.

## 공통 기준

`backend/src/contracts/config/salary.config.ts`에서 구간을 조정한다.
`estimateMarketAnnualSalary`를 선수 협상, AI 초기 선수단 연봉 추산, AI 일반/레전드 영입 제안에 함께 사용한다.
기준 능력은 현재 핵심 8개 스탯의 평균이며 화면의 카드 OVR과 동일하다고 가정하지 않는다.
선수 이름이나 국적에 따른 고정 가격은 없다.

| 평균 능력 | 기본 연봉 |
| --- | --- |
| 60 | 3,000만원 |
| 70 | 1억 |
| 75 | 1억 5,000만원 |
| 80 | 3억 |
| 85 | 5억 |
| 90 | 8억 |
| 92 | 10억 |
| 94 | 20억 |
| 95 | 25억 |
| 98 | 35억 |
| 100~119 | 40억 |

구간 사이는 선형 보간하며 100만원 단위로 올림한다. 최하위 구간(능력 0)은 1,000만원부터 시작한다.
신뢰·성격·팀 전력·계약 기간·약속에 따른 기존 협상 보정은 유지한다.
신규 계산 요구액은 보정 후 최대 40억. AI는 시장 기본값에 15%를 가산하되 같은 상한을 따른다.
현재 연봉에 매년 15%를 반복 가산하던 인플레이션은 없앴다.

## 기존 세이브 / 변경하지 않는 항목

- 체결된 계약, 저장된 제안/역제안, 이적료, 선수 스탯을 일괄 수정하지 않는다.
- 현재 계약 연봉 하한은 유지하므로 기존 고액 계약(40억 초과 포함)의 재계약/이적 협상은 이전 연봉보다 낮아지지 않을 수 있다.
- 이후 평가되는 협상과 신규 AI 제안, 명시적 계약이 없는 선수의 추산 비용부터 새 공식이 적용된다.
- 기존 AI 예산 상한과 사용자 구단 자금 시스템은 이번 변경에 포함하지 않는다.
- 스키마 변경/마이그레이션/재시드가 필요 없다. 실행 중인 백엔드에는 코드 재시작/재빌드가 필요하다.
