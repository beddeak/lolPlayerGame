# 카드 아트 테스트와 세이브 삭제

## 테스트 카드

- `backend/data/development-seed.json`: `test_viper_worlds_2021`, BLG 후보 명단.
- `Viper (2021 TEST)`는 기존 Viper와 다른 선수 ID가 생성되도록 구분한 테스트 전용 선수다. 실제 선수 중복 금지 규칙은 변경하지 않았다.
- `WORLDS_2021_TEST`는 자동 레전드 이벤트 대상으로 활성화하지 않는다.
- 스탯은 현재 2026 Viper 값을 복사한 임시값이다. 잠재력 119는 훈련 표시 테스트용이며, 정식 2021 밸런스가 아니다.
- 원본: `frontend/public/player-cards/2021viperEDG.png`. 사용자가 숫자를 제거한 이미지를 그대로 사용하며 이미지는 수정하지 않는다.
- OVR 가림 배경 없이 숫자 텍스트만 표시한다. OVR은 현재 8개 스탯 평균 반올림이며, 하단 숫자도 커리어 현재 스탯이다. 커리어가 없을 때만 기본 카드 스탯을 사용한다.
- 선수단 후보 카드·상세보기와 훈련 화면의 선수 상세보기에서 사용한다. 훈련 후 갱신된 선수 객체를 사용하여 열린 상세보기에도 변경값이 반영된다.
- `npm run seed:catalog`는 공용 카드/구단 템플릿에 적용한다. 후보는 **새 게임부터** 배치되며 기존 세이브 선수단에는 추가하지 않는다.
- 테스트 종료 시 BLG의 해당 bench 항목을 제거할 수 있다. 시드는 기존 DB 카드/선수를 자동 삭제하지 않는다.

## 레전드 바이퍼 카드 연출

- `PlayerCardArtwork`에서 원본 PNG 위에 CSS/SVG 장식 레이어를 올린다. 방패 실루엣에 맞춘 표시용 클리핑으로 바깥 여백을 정리하지만 이미지 파일은 변경하지 않는다.
- 은빛 홀로그램 광택, 은색·샴페인색 테두리 빛, 가장자리 별빛 6개를 공통 적용한다. 선수단·상세보기·POM에서 같은 컴포넌트를 사용한다.
- 장식은 `aria-hidden`/`pointer-events: none`으로 처리하고 OVR·스탯 텍스트 아래에 배치한다. 일반 사진에는 효과를 붙이지 않는다.
- 매 프레임 JavaScript나 추가 라이브러리 없이 CSS 애니메이션으로 동작한다. `prefers-reduced-motion`에서는 정적인 장식만 남긴다.
- 카드/결과창/선수단 검사와 프론트 빌드로 호환성을 확인한다. 현재 연결된 브라우저가 없어 실제 애니메이션 화면 검증은 별도 확인이 필요하다.

## 세이브 삭제

커리어의 `← 세이브 목록` → 해당 구단 카드의 `세이브 삭제` → `삭제` 입력 → `영구 삭제`.

`DELETE /careers/:id`는 로그인된 소유자만 사용할 수 있다. 커리어 잠금과 트랜잭션 안에서 삭제하고 DB 외래키가 해당 진행 기록을 정리한다. 해고된 커리어도 삭제할 수 있다. 계정, 공용 선수/카드/구단, 다른 세이브는 유지한다. 삭제는 복구할 수 없다.

프론트는 중복 요청과 이전 로그인 세션의 늦은 응답을 차단한다. 응답 유실 시 목록을 다시 확인하며 DELETE를 자동 재시도하지 않는다.

## 검증 명령

프론트: `npm run test:save-delete`, `npm run test:app`, `npm run test:card-artwork`, `npm run test:squad`, `npm run build`.

백엔드: `npm run seed:check`, `npm run test:e2e:isolated -- --testPathPatterns=manager-career.e2e-spec.ts`.

삭제 E2E는 임시 DB의 테스트 세이브만 삭제한다. 개발 DB 세이브로 삭제 테스트하지 않는다.
