# 2026 기본 능력치 재조정 — 2026-09-24

## 범위와 해석

`backend/data/development-seed.json`의 일반 시즌 카드 285명, 기본 능력치 8개를 수정했다. 공식 선수 평점이나 객관적인 실력 측정치가 아니라 사용자가 정한 전 세계 공통 등급표에 맞춘 **1차 게임 밸런스안**이다. 선수 전원의 개별 경기/VOD를 분석한 결과는 아니다. 세부 개인 능력은 기존 시드의 상대적인 강약을 출발점으로 삼았다.

- 국적은 평가 입력에 사용하지 않는다. 동일 리그의 외국인 선수와 현지 선수에 같은 방법을 적용한다.
- 리그·팀 기준은 초기 생성 능력치를 정하기 위한 편집 기준이다. 시뮬레이션에 숨은 리그 페널티를 추가하지 않았다.
- 나이·국적·소속·로스터·성격·구단 케미·감독 신뢰·사진 경로는 그대로다.
- 2021 Viper TEST 카드는 카드 표시용 테스트 데이터이므로 100×8, potential 119를 유지했다. 일반 선수 평균에는 포함하지 않는다.
- 현재 세이브 및 DB는 변경하지 않았다. 역할/챔피언 유형 숙련도 구조도 변경하지 않았다.
- 기존 potential 생략 카드는 importer에서 기본 8스탯 최댓값을 잠재력으로 사용한다. 기본 능력 하향이 잠재력까지 낮추지 않도록 **수정 전 최댓값**을 potential에 명시했다. 성장의 시스템 상한 119는 그대로다.

## 근거와 한계

공식 [LoL Esports 경기 결과](https://lolesports.com/en-US/leagues/msi)를 확인했다. 2026 First Stand에서 TSW는 G2와 BFX에 각각 0:3으로 졌지만, MSI에서는 TES를 3:1로 이겼다. 따라서 약한 지역이라는 이유로 모든 선수의 강점을 지우지 않는다. G2의 First Stand 결승 진출과 LYON의 MSI G2전 3:0도 서구권 강점을 모두 낮추지 않는 참고 자료다.

이 결과는 리그 간 초기 기준을 잡는 참고일 뿐, 개인 메카닉·멘탈 값을 직접 산출하지 않는다. 모든 팀의 최근 리그 경기나 모든 선수의 현시점 폼을 정밀 재평가한 자료로 취급하지 말 것. 특히 구단 기준값과 개별 override는 밸런스 판단이며 향후 사용자 조정 대상이다.

## 적용 방법

`2026-rating-calibration.json`에 팀별 기준과 개별 조정값을 기록했다. 기준 평균은 최종 OVR을 강제로 고정하는 값이 아니다.

1. 일반 선수의 기존 8스탯 평균과 소속 팀 주전 평균을 구한다.
2. 선수 목표 평균 = 팀 기준 + 0.8 × (기존 선수 평균 − 기존 팀 주전 평균).
3. 멘탈은 지역과 무관하게 `min(기존값, round(80 + (기존값 − 85) × 0.75))`로 정규화한다. 개별 override가 있으면 해당 판단을 우선한다.
4. 나머지 7개 스탯은 목표 평균을 맞추되 기존 개인 프로필의 평균 대비 차이를 1.25배로 남긴다. 장단점을 전부 같은 숫자로 만들지 않는다.
5. 개별 override를 적용한 후 모든 스탯은 기존값 이하, 0~100 정수로 제한한다. 따라서 이번 수정으로 상향된 기본 스탯은 없다.
6. 기존의 실효 잠재력을 보존한다. 소속 없는 4명은 기존 카드 키에 해당하는 팀 기준만 참고하며 실제 로스터에는 배치하지 않는다.

후속 변경에 이 공식을 반복 적용하면 누적 하향되므로 자동 실행 스크립트로 연결하지 않았다. 이전 값과 최종 값은 `2026-rating-changes.json`에 남아 있다. 이는 스탯 복원/검토용 기록이지 전체 DB 백업은 아니다.

## 검증 및 반영

- 변경 기록의 285명과 실제 JSON 값 일치, 모두 정수·0~100·기존값 이하·잠재력 이하 확인.
- 기본 스탯/potential을 제외한 전체 JSON 내용의 해시 일치 확인. 로스터 등 다른 입력 데이터 불변.
- `npm run seed:check`: 286 카드, 56 구단, 2 테마 구조 검증 통과. LCP·CBLOL 로고 16개 파일 누락 경고는 남아 있다.
- 시드 관련 단위 테스트 3개 스위트, 126개 통과.

DB 카탈로그에 반영하려면 backend에서 `npm run seed:catalog`. 이 작업에서는 실행하지 않았다. 기존 커리어의 현재 스탯은 별도 데이터이므로 카탈로그 반영만으로 덮어쓰지 않으며, 새 커리어로 변경된 기본 능력치를 확인한다.
