# 정규시즌 자동 진행

시즌 화면의 **플레이오프까지 스킵 · 활동 계획**에서 시작한다. 관리자 권한이 아닌 본인 세이브용 기능이다.

## 계획

- 팀 스크림 전술 한 가지를 선택한다. 실제 경기 전술을 바꾸는 설정은 아니다.
- 스크림/휴식을 1~8주 주기로 편집한다. 기본값은 스크림 → 휴식 반복이다.
- 준비 기간 개인 훈련을 선수별 기본 능력치 한 가지로 지정하거나 생략한다.
- 개인 훈련은 기존 준비 기간·주간 횟수·성장 상한을 그대로 따른다. 정규시즌과 휴식 주에는 하지 않는다.
- 이미 이번 주에 실행한 활동은 유지하고 중복 실행하지 않는다. 주기는 월요일 기준 달력 주차로 계산한다.
- 전술 숙련도·케미가 모두 최대인 스크림은 휴식으로 대체한다. 컨디션·폼이 모두 최대라 회복할 필요가 없으면 휴식을 실행하지 않고 진행한다. 이때도 개인 훈련은 하지 않는다.
- 성장 상한이나 컨디션 부족 등 기존 훈련 규칙을 위반하면 중단하고 오류를 보여준다. 개인 훈련 후 휴식을 요청한 주도 직접 정리해야 한다.

## 진행과 저장

요청 한 번에 활동 하나, 경기 한 세트, 또는 하루를 기존 서비스로 처리한다. 날짜만 강제로 변경하지 않는다. 밴픽은 이 자동 진행 경로에서만 자동 완성하며, 일반 경기의 수동 밴픽 규칙은 유지한다.

현재 감독 구단의 대상 스플릿에서 ROUND_ROBIN/GROUP/SWISS 단계를 처리하고, PLAY_IN/토너먼트 전에는 멈춘다. 다른 지역 경기도 달력 순서대로 처리한다. 국제대회·면담 등 사용자 결정 이벤트, 이적시장, 감독 해임, 일정 범위 이탈 시에도 멈춘다. 진출하지 못한 경우 다음 스플릿을 계속 넘기지 않는다.

중단 버튼은 현재 요청을 마친 뒤 멈춘다. 완료된 결과는 이미 저장되며 되돌리지 않는다. 통신 실패 시 자동 재시도하지 않는다. 화면을 닫으면 추가 요청을 보내지 않는다. 다시 실행하면 최신 저장 상태를 조회하고 **현재 주부터 새 계획 주기**를 적용한다. 실행 계획 자체는 서버에 예약 저장되지 않으며 브라우저를 닫은 동안 진행하지 않는다.

JWT 소유권, 공유 자동 진행 잠금, 날짜/경기/훈련 기록 기반 커서, 기존 트랜잭션과 기대 날짜 검증으로 중복 실행을 방지한다. DB 스키마 변경은 없다.

로그인 토큰이 만료되거나 유효하지 않으면 자동 진행을 멈추고 재로그인 안내를 표시한다. 이미 저장된 커리어는 유지하며, 재로그인 후 최신 상태에서 다시 계획을 확인한다. 실패한 요청을 자동으로 재실행하지 않는다. 다른 계정으로 로그인한 뒤 도착한 이전 토큰의 오류는 새 세션을 종료하지 않는다.

## 검증

- 정책/DTO 단위 테스트: 주차 계산, 반복 패턴, 정규/녹아웃 분류, 입력 제한.
- 격리 MySQL E2E: LEC 10팀 45경기 완료, 플레이오프 미시작, 주간 활동 중복 방지, 준비 기간 개인 훈련, 휴식 주 개인 훈련 제외, 인증·소유권·오래된 커서, 수동 이벤트 보존.
- `frontend npm run test:season-skip`: 확인 체크, 계획 전송, 이중 클릭, 중단, 통신 실패, 언마운트, 대상 변경. 제어된 컴포넌트 핸들러 검사이며 실제 브라우저 시각 검사는 별도다.
- `frontend npm run test:api-session`, `npm run test:app`: JWT 인증 오류 구분, 하위 화면의 인증 만료 전파, 시작 시 만료 토큰, 이전 세션 응답 격리, 재로그인과 요청 재실행 방지.
