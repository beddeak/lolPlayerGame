# 실제 챔피언 밴픽 · 자유로운 포지션 배정

## 적용 범위

- 새로 시작하는 시리즈는 DraftState version 3. 실제 챔피언 173명과 한글 이름/이미지를 사용한다.
- Riot Data Dragon `16.19.1`의 `ko_KR/champion.json`을 고정한 명단이다. 최신 목록을 실행 때마다 불러오지 않는다.
- 기존 version 1/2 시리즈는 마지막 세트까지 기존 Variant 규칙으로 이어간다. 기존 커리어에서 다음 시리즈를 시작하면 새 규칙을 사용한다. 새 커리어 생성, seed 실행, DB 마이그레이션은 필요하지 않다.
- 협곡 실시간/배속 관전 화면과 개별 스킬 시뮬레이션은 이번 범위가 아니다.

## 진행

1. 기존 First Selection으로 진영과 픽 순서를 선택한다.
2. 5밴/5픽의 20턴 밴픽. 모든 챔피언이 포지션 제한 없이 선택 가능하다. 추천 포지션 필터는 목록 탐색용이다.
3. 양 팀 픽이 끝나면 AI 추천 배치를 제시한다. 내 팀은 다섯 포지션의 선택 상자 또는 드래그로 챔피언을 교환한다.
4. **배치 확정** 후 **경기 시작**. 한 챔피언을 두 선수에게 배정하거나, 상대 픽/밴된 챔피언을 배정할 수 없다.
5. 배치 제한 시간은 30초. 시간이 끝나면 서버 추천 배치를 확정한다. 아직 확정하지 않은 화면상의 편집은 저장되지 않는다.
6. BO3/BO5 피어리스는 양 팀이 이전 세트에 **픽한 챔피언**을 막는다. 이전 세트 밴은 다시 선택 가능하다.

### 차례 표시와 소리

- 내 차례는 금색 중앙 안내/타이머, 활성 팀과 현재 밴·픽 슬롯, 상단 20턴 순서표로 표시한다. 블루/레드가 아니라 관리 구단 ID로 내 차례를 판단한다.
- 상대 차례에는 상대 구단 이름과 대기 안내를 표시한다. 미리보기는 가능하지만 확정은 차단한다.
- 효과음은 기본 활성화 설정이지만 브라우저 사용자 입력 전에는 재생하지 않는다. 기존에 끈 설정은 유지한다. 켜기/끄기는 무음이며 테스트 버튼이나 미리듣기 소리는 없다.
- 테스트용 합성 효과음 생성 코드를 제거했다. 차례·밴·카운트다운·배치 확정음은 없고 서버가 확인한 픽 확정에만 로컬 `draft-pick-lockin.ogg`를 재생한다. BGM은 별도로 유지한다. 출처/권리 구분은 `frontend/public/audio/README.md`에 기록했다.
- 픽 파일은 오디오 컨텍스트 활성화 시 한 번 로드/디코딩하여 재사용한다. 픽 이벤트 중복을 차단한다. 로딩 중/실패/코덱 미지원 시 무음이며 합성 대체음은 없다. 늦은 로드가 과거 픽을 다시 울리지 않는다.
- 저장 중·오류·숨겨진 탭에서는 새 효과음을 울리지 않는다. 음소거와 화면 종료 시 노드/리스너를 정리하되 브라우저당 오디오 컨텍스트는 재사용한다. 중단 시 다음 입력으로 재개한다. 오디오 오류는 경기 진행에 영향을 주지 않는다.
- 자동 테스트는 픽 파일 재생 경로와 합성음 미사용을 검증하며 실제 스피커 출력까지 보장하지 않는다.
- `npm run test:draft-audio`는 모의 Web Audio로 검증하며 실제 소리를 출력하거나 브라우저를 열지 않는다.

### 밴픽 배경음악 (효과음과 별도)

- 사용자 지정 영상: [Prelude To Battle - The Trilogy [Champ Select(밴픽)] | LCK Music](https://www.youtube.com/watch?v=V1gTYew5k4U), LCK 공식 채널. YouTube oEmbed 메타데이터로 제목·채널·임베드 제공을 확인했다.
- 영상 팝업 없이 사용자가 `frontend/public/audio`에 추가한 `Prelude To Battle - The Trilogy [Champ Select(밴픽)]   LCK Music.mp3`를 재생한다. 원본 파일명을 보존하고 URL 인코딩하여 연결했다. 설정은 `DraftBackgroundMusic.tsx`의 `SOURCE`다.
- 밴픽 진입 시 기본 음량 25%로 반복 재생한다. 작고 독립적인 음소거 버튼만 표시하며 선택은 `lol-manager:draft-bgm:v2`에 저장한다. 기존 영상창의 수동 켜기 설정과 분리했다.
- 자동재생을 브라우저가 차단하면 다음 클릭/키 입력에서 재시도한다. 음원 누락은 안내만 표시하고 경기 API에 영향을 주지 않으며 클릭마다 재요청하지 않는다.
- 진영 선택→밴픽→배치 동안 오디오 하나를 유지하고 매 턴 재시작하지 않는다. 탭을 숨기면 일시정지, 복귀 시 같은 위치에서 재생한다. 결과/피드백/닫기에서 일시정지하고 소스·리스너를 정리한다. iframe과 외부 플레이어 SDK는 사용하지 않는다.
- 검증: `npm run test:draft-bgm`, `npm run test:match-flow`, `npm run test:draft-audio`. 브라우저/실제 청음 검증과 구분한다.
- 참고: [브라우저 자동재생 정책](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay).

### 목록 렌더링 비용

- 제한 목록을 Set/Map 조회로 만들고 검색 결과와 173개 카드 요소를 메모한다. 타이머는 250ms로 마감 시각을 확인하되 표시 초가 달라질 때만 상태를 갱신한다. 시계만 바뀌면 카드 하위 트리는 다시 생성하지 않는다.
- 카드의 화면 밖 내용은 `content-visibility: auto`로 렌더링을 생략하며 이미지 비동기 디코딩/지연 로딩/고정 비율을 사용한다. 미지원 브라우저에서도 기본 그리드는 유지된다. 전체 화면 블러와 지속적인 텍스트 발광 애니메이션은 제거했다.
- 카드 요소 동일성은 자동 테스트로 확인한다. 실제 저사양 브라우저의 FPS 측정은 별도다.

결과의 선수별 지표에 해당 포지션의 챔피언 이름을 함께 표시한다. 픽/밴 이름과 이미지 주소, 배치, 명단/밸런스 버전은 경기 기록에 남긴다.

## 데이터와 밸런스는 별개

- `backend/src/drafts/data/riot-champions.ts`: 공식 명단/식별자/한글 이름/이미지 파일과 기초 메타데이터의 고정 스냅샷.
- `backend/src/drafts/champion-catalog.ts`: 추천 포지션, 포지션 적합도, 초·중·후반/라인전/한타/앞라인/이니시/보호/피해 구성 등 **자체 게임 밸런스**.
- `backend/src/drafts/champion-balance.ts`: 상성·조합·배치 평가 및 경기 보정.
- `backend/src/drafts/champion-draft-ai.ts`: 공개된 픽과 남은 후보로 판단하는 AI.

현재 밸런스 `prototype-2`는 클래스/기초 메타데이터 기반 프로필에 주요 챔피언별 보정을 추가한 **실험용 수치**다. 실제 패치 승률이나 173명 전원의 세밀한 실력/스킬 모델을 재현한 것이 아니다. 화면에도 테스트용 자체 평가임을 명시한다. 선수별 개별 챔피언 숙련도는 이번에 임의로 만들어 저장하지 않는다. 기존 선수 능력치와 역할 체계는 유지한다.

모든 포지션은 허용한다. 적합도/상대의 사거리와 교전 특성/팀의 피해 구성·앞라인·보호·성장성을 계산한다. `damage`, `waveClear`, `objectiveDamage`를 별도로 두어 딜러·파밍·오브젝트 공격력이 없는 조합에 강한 감점을 적용한다. 보호력만 쌓아 딜 부족을 상쇄할 수 없다. Support 태그 자체는 감점하지 않으며 딜이 나오는 메이지 서폿과 가능한 비주류 배치는 유지한다. 포지션 적합도가 매우 낮으면 추가 감점한다. 최종 보정 범위는 -32~+10이며 승패·개인 지표에 동일하게 적용한다. 전투 스킬, 아이템 빌드, 오브젝트별 턴은 아직 모델링하지 않는다.

`champion-composition.spec.ts`는 정상 조합/5유틸 서폿/5탱커 서폿/5원딜과 선수 능력 차이를 각 512개 seed로 실제 승패 계산까지 검증한다. 특정 태그의 자동 패배 규칙은 없으며 극단적인 체급 차이에서는 결과가 달라질 수 있다. 이미 저장된 경기 결과는 수정하지 않는다.

동일한 챔피언 보정은 승패 계산뿐 아니라 개인 KDA 배분·DPM·골드·GD@15·CSD@15에도 적용한다.
변경된 지표의 평점은 기존 POG/POM 선정과 경기 후 상태 계산으로 이어진다. 효과는 경기 내 유효 능력에만 적용되며,
선수의 저장된 기본 능력치를 수정하지 않는다. 능력 범위(0~119), 킬/데스 합계 및 라인 지표의 양 팀 합계 0을 유지한다.
기존에 저장된 경기 결과는 다시 계산하지 않고, 수정 후 새로 진행한 경기부터 적용한다.

AI는 최대 32개 포지션 마스크를 쓰는 최대 가중치 배정으로 픽의 역할 중복/빈자리를 평가한다. 팀 전술·선수의 현재 기본 능력·공개된 상대 픽·조합을 고려하고, 점수가 근접한 상위 후보 사이에서 시리즈 seed에 따른 차이를 준다. 새로고침으로 AI 선택을 다시 뽑을 수 없다. 실제 챔피언 모드의 First Selection도 고정 선픽/블루 대신 픽 가치와 안정적인 seed를 사용한다.

AI는 세트마다 초반 압박·한타·후반 캐리 보호·포킹·픽오프·사이드 운영 중 하나를 중심으로 조합을 구성하고 상대 공개 픽에 대응한다. 밴의 대체재와 우리 선픽 기회비용도 평가한다. 적용 경로와 검증은 [밴픽 AI 전략 다양화](DRAFT-AI-STRATEGIES.md)를 참고한다.

## 안전장치와 검증

- 기존 커리어 소유권 확인·자동 진행 잠금·트랜잭션을 그대로 사용한다.
- 밴픽은 expectedStep, 배치 확정은 expectedRevision으로 중복 요청과 오래된 화면을 거절한다.
- 자동 진행/AI 전용 경기는 밴픽과 배치를 함께 확정하고, 일반 사용자 경기의 배치를 임의로 건너뛰지 않는다.
- 외부 이미지가 실패하면 이름을 표시하며, 이미지 서버 없이도 선택/시뮬레이션은 가능하다.
- backend: `npm test -- --runInBand`, `npm run test:e2e:isolated -- app.e2e-spec.ts test-admin.e2e-spec.ts`
- frontend: `npm run test:champion-draft`, `npm run test:match-flow`, 기존 draft/first-selection/intermission/match-report 검사.
- 화면 검사는 제어된 React 컴포넌트 렌더/핸들러 검사이며 실제 브라우저 시각 검증과 구분한다.

## 출처 및 배포 주의

- 공식 데이터: https://ddragon.leagueoflegends.com/cdn/16.19.1/data/ko_KR/champion.json
- Data Dragon 문서/정책: https://developer.riotgames.com/docs/lol

공개된 데이터가 별도 게임 제작 권한까지 부여하는 것은 아니다. Riot 개발자 정책은 Riot IP를 활용한 게임 제작을 제한한다. 이번 기술 구현이 공개 배포 허가를 뜻하지 않으며, 외부 배포/상용화 전 권리와 정책 검토가 필요하다.
