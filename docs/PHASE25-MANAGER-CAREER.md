# PHASE 25 — 팬 지지·이사회 신뢰·경질

PHASE 24의 국내 리그·달력·이적 흐름에 감독 평가를 연결한다.
팬 지지와 이사회 신뢰는 별도 수치이며, 팬 지지만 낮다고 경질되지 않는다.

## 사용 방법

시즌 허브의 감독 평가 영역에서 팬 지지, 이사회 신뢰, 공식 시리즈 전적,
기대 승수, 경고 상태와 최근 평가 이유를 확인한다. 별도 seed는 필요 없다.

- 두 평가는 각각 65로 시작하며 0–100 범위다.
- 공식 국내 리그 **시리즈가 끝났을 때** 한 번 평가한다. BO3/BO5의 개별 세트,
  독립 연습 경기, AI 팀끼리의 경기는 사용자 감독 전적에 포함하지 않는다.
- 스플릿 시작 시 현재 주전 5명의 공개 기본 스탯 8개로 기대 전력을 고정한다.
  경기 직전에 약한 선수를 배치한다고 해당 스플릿의 기대치가 낮아지지 않는다.
- 스플릿 종료 평가는 정규시즌 순위가 아니라 플레이오프를 포함한 최종 진출 단계와
  순위를 사용한다. 같은 단계의 동순위 탈락은 동순위로 유지한다.
- 실제 영입·방출·계약 만료 전후의 주전 전력 변화는 다음 날짜 처리에서 반영한다.
  후보 영입이나 재계약만으로 주전이 그대로라면 추가 점수를 주지 않는다.
- 평가 뉴스는 결정을 요구하지 않는 완료 이벤트다. 읽지 않았다고 일정이 멈추지 않는다.

현재 수치는 게임용 초기 밸런스이며 실제 구단의 평가 방식을 재현한다는 뜻은 아니다.
조정값은 `backend/src/manager-career/config/manager-career.config.ts`에 모았다.

## 경고와 경질

아래 **성적·팬 지지·이사회 신뢰 조건이 모두 충족**되어야 한다.

| 단계 | 성적 조건 | 팬 지지 | 이사회 신뢰 | 추가 조건 |
| --- | --- | --- | --- | --- |
| 경고 | 부진 | 40 이하 | 50 이하 | 평가된 공식 시리즈 6회 이상 |
| 경질 | 부진 지속 | 25 이하 | 35 이하 | 경고 후 최소 3시리즈 완료 |

부진은 6연패이거나, 승률 35% 이하이면서 기대 승수보다 실제 승수가 1.5승 이상
부족한 경우다. 오랫동안 잘했던 감독도 최근 심한 연패는 평가받는다.
2연승 후 성적이 개선되거나 팬 지지 45 / 이사회 신뢰 55 중 하나를 회복하면 경고를 해제한다.
영입이나 스플릿 요약 평가만으로 경고·유예 절차를 건너뛰고 바로 경질하지 않는다.

연도가 바뀌어도 평가, 누적 전적, 연승·연패, 경고 및 남은 유예는 유지한다.
새해라는 이유만으로 경질 위험을 초기화하지 않는다.

경질 시 마지막 경기 결과와 저장을 남긴다. 기존 팀을 저장의 기준 팀으로 유지하되
감독의 고용 상태를 별도로 `DISMISSED`로 기록한다. 기록 조회와 화면 이동은 가능하지만
날짜 진행·경기·훈련·선수단·계약·이적 등 감독 운영 변경은 서버에서도 409로 거절한다.
현재는 커리어가 읽기 전용으로 정지한다. 재취업·사임·감독 은퇴는 아직 구현하지 않았다.

## 기존 저장과 API

```text
GET /careers/:careerId/manager
GET /careers/:careerId/calendar → manager 필드 추가
```

소유 계정만 조회할 수 있다. 내부 기대 전력 자료와 선수 잠재력은 노출하지 않는다.
조회만으로 평가 상태·뉴스·경기를 생성하지 않는다.

기존 저장은 다음 일정 처리·리그 준비 시 평가 상태를 초기화한다. 그때 이미 끝난 공식 경기와
스플릿은 처리 기준선으로만 기록하여 **과거 성적을 소급 감점하지 않는다**.
평가용 전력 스냅샷이 없는 기존 이적 기록도 소급 평가하지 않는다.

## 구조와 중복·동시 요청 보호

- `manager-policy.ts`: 저장소와 분리한 순수 평가·경고·회복 정책.
- `ManagerCareerService`: 기대치 고정, 경기·시즌·이적 평가, 조회, 뉴스 기록.
- `manager-access.ts`: Career 잠금 및 현재 감독 권한 검사.
- `ManagerCareerState`: 고용 상태와 평가. 달력의 Career 저장이 이를 덮어쓰지 않도록 별도 테이블.
- `ManagerReview`: `(careerId, sourceKey)` 고유 키로 시리즈·스플릿·이적별 한 번만 기록.

Career를 먼저 잠그고 평가한다. 리그는 최종 세트 결과와 다음 단계 진출 처리를 마친 후
평가하므로 경질로 마지막 경기 결과가 취소되지 않는다. 경기 저장 직전에도 권한을 재검사한다.
이적의 중복 방지 단위는 선수/연도가 아닌 **TransferRecord ID**다. 변화가 없는 후보 영입이
같은 선수의 후속 주전 방출 평가를 숨기지 않는다.

날짜 진행과 경기 요청이 겹칠 때 잠금 이후의 최신 날짜를 사용한다.
이미 진행한 날짜보다 과거로 이벤트를 처리하는 요청은 거절하고 평가 연도도 되돌리지 않는다.

## 명시적인 범위 밖

- 미구현인 실제 국제대회 경기·진출 결과, 라이벌 관계, 선수 인기도, 언론·재정 압박은
  가짜 수치로 평가하지 않는다. First Stand/MSI/Worlds는 여전히 달력 예약 기간만 있다.
- 재취업 제안과 새 구단 선택, 사임·은퇴·게임 종료 선택은 후속 기능이다.
- 경질 상태에서 AI만 계속 돌아가는 관전자 모드는 포함하지 않는다.
- Player / Theme / PlayerCard 카탈로그, 현재 선수 스탯과 기존 시뮬레이션 계산은 변경하지 않는다.
