# 그룹별 리그 화면과 진출 판정

## 적용 범위

- 시즌 화면은 `GROUP` 단계에서 **저장된 참가팀의 groupCode**로 그룹을 나눈다. 그룹마다 1위부터 순위, 구단 로고, 경기 수, 승패, 세트 득실, 내 구단을 표시한다.
- LCK Split 1: 바론 / 장로 그룹. 상대 그룹과 경기하며 그룹 합산 점수와 그룹 내 개인 순위를 별도로 표시한다.
- LCK Split 3: 레전드 / 라이즈 그룹.
- LPL: 기존 게임 포맷을 유지한다. Split 1 S/A/B, Split 2 A/B/C/D 및 등봉조(Ascend)/열반조(Nirvana), Split 3 Ascend/Nirvana.
- 플레이인·플레이오프는 기존 대진표를 유지한다. 일반 풀리그는 단일 순위표다. 확정 전인 그룹은 대기 안내를 표시한다.

이 작업은 LPL의 모든 세부 규칙을 실제 2026 포맷으로 다시 설계한 작업이 아니다. 현재 카탈로그 규모와 기존 스플릿별 포맷을 유지하면서, 이미 생성된 조별 경기와 화면/진출 판정을 일치시킨다. 참가팀이 부족한 커리어는 기존 축소 대회 동작을 유지한다.

## LCK 집계

- **새로 생성하는 10팀 Split 1만** 마지막 그룹 라운드에 같은 조내 시드끼리 슈퍼 위크 BO5를 배치한다. 나머지 경기는 BO3. 총 25경기 중 BO5 5경기다.
- 그룹 승점은 일반 경기 1점, 슈퍼 위크 2점. 팀 개별 기록은 모두 1승이며 실제 세트 득실을 사용한다.
- 승리 그룹 1·2위 및 패배 그룹 1위 PO 직행. 승리 그룹 3~5위 및 패배 그룹 2~4위 플레이인 진출. 플레이인 시드는 진출 자격 확정 후 개인 전체 성적으로 정렬한다.
- 승점 동점이면 합산 세트 득실로 비교한다. **완전 동률의 게임용 단순화 규칙**은 기존 상위 시드를 가진 그룹 우선이다. 실제 컵의 별도 그룹 타이브레이커 경기를 구현한 것은 아니다. 이 결정 사유는 화면에 표시한다. 진행 중 완전 동률은 동률로 표시하고 완료 후에만 최종 시드 기준을 적용한다.
- 그룹 내 개인 순위는 승수 → 세트 득실 → 기존 시드다. 공식 승자승 점수/평균 승리 시간 등을 모두 재현하지 않는다.

LPL Split 1의 PO 직행권은 전체 통합 순위 상위 4팀이 아닌 S 그룹 상위 4팀에 준다. Knights Rival은 S 그룹 잔여 팀, A 상위 4팀, B 상위 2팀에서 최대 8팀을 선정한다.

## 기존 세이브

- DB 마이그레이션/리시드 불필요. 구단, 선수, 세이브, 저장된 조 편성과 경기 결과를 삭제하거나 재작성하지 않는다.
- 기존 LCK `A`/`B` 조는 표시명만 바론/장로로 바꾼다.
- 슈퍼 위크 설정이 없는 기존 대회의 경기 방식/승점은 유지한다. 기존 BO3를 BO5로 바꾸지 않는다.
- 완료되어 편성된 다음 단계 참가팀도 소급 재편성하지 않는다. 아직 생성하지 않은 다음 단계부터 수정한 진출 판정을 사용한다.
- 백엔드 API `stage.groups`가 표시와 진출 로직의 공통 계산 결과다. 기존 `stage.standings`는 호환성을 위해 유지한다. 백엔드 재시작 후 화면을 새로고침하면 그룹 표시가 적용된다.

## 검증

- `league-groups.spec.ts`: 저장 데이터 불변, 조별 순위, 기존 A/B, 슈퍼 위크 승점, 미완료 경기 제외, 동점 결정, 모든 그룹 종류.
- `leagues.service.spec.ts`: LCK 25경기/슈퍼 위크와 조별 진출, LPL 조내 대결/S그룹 직행, 축소·전체 인원 3개 스플릿 진행.
- `league-schedule.spec.ts`: 대진 중복/같은 라운드 중복 출전 없음, 기존 일정 호환.
- 프론트 `test:league-groups`, `test:calendar`, `test:theme`: 그룹별 표/내 구단 순위/대진표 전환/텍스트 대비. 실제 브라우저 시각 검사는 하지 않음.
