# Tactical environment model — Stage 3/4

이 모델은 실제 경기 DB에 연결되지 않은 **개발용 V2 규칙 선택지**다. 기존 10분 실험과 과거 세이브의 규칙은 바꾸지 않는다. 구조물·중립 몬스터도 챔피언과 동일한 HP/공격 Resolver에서 처리하며, 목표를 선택하거나 시간이 됐다는 이유로 획득 또는 승리를 지급하지 않는다.

## 공식 참고값과 자체 모델 경계

2026-09-27에 Riot 공식 문서를 확인했다. 기준은 **26.1 일반 협곡**이며 최신 라이브 패치나 Swiftplay 재현이 아니다. 중간 패치 전체 변경 이력을 감사했다는 의미도 아니다.

26.1 참고: 외곽 포탑 9000 HP, 내곽 5000, 억제기 포탑 4750, 넥서스 포탑 3500. 방어력 60. 방패는 영구 유지되고 손실 HP 10/25/45/70/100%마다 120골드. 외곽은 11분부터 분당 방어력 15/골드 10 감소, 감소 한도 60/40. 첫 포탑 근처에 300골드 분배. 근접 챔피언의 포탑 피해는 1.2배, 미니언은 0.6배. 넥서스 포탑 재생 HP 40%. 과성장은 준비 90초, 최소 구간 60초, 성장 구간 240초이며 백도어 보호 중 발동하지 않는다. ([Riot 26.1](https://www.leagueoflegends.com/en-us/news/game-updates/patch-26-1-notes/))

넥서스 포탑 재생 시간 3분은 [Riot 25.S1.1](https://www.leagueoflegends.com/en-us/news/game-updates/patch-25-s1-1-notes/)을 참고한다. 유충 8분·재생성 없음, 전령 15분은 [Riot 25.09](https://www.leagueoflegends.com/en-us/news/game-updates/patch-25-09-notes/)를 참고한다. 바론 20분은 위 26.1 문서의 Game Start Time 기준이다.

**넥서스 포탑의 방패는 비활성**이다. 26.1 문서의 개요는 제외한다고 하지만 상세 목록은 방패를 명시하여 서로 충돌한다. 임의로 한쪽을 공식 정답이라고 결정하지 않았다.

다음은 명시적 **MODEL**이며 Riot 정확한 수치로 표시하면 안 된다.

`environment-rules.ts`가 위 숫자의 단일 입력 원본이다. 입력이 동결된 뒤 실행 중 설정을 읽어 바꾸지 않는다. `EnvironmentState`에는 획득 수, 실제 보유자, 버프 만료, 영혼/장로 조건, 첫 포탑 지급 상태가 포함되며 체크포인트에 함께 보존된다.

## Resolver 연결 계약

1. `initializeEnvironment`: 양 진영 각 15개 구조물과 생성 전 중립 개체 정의. 유충·전령·바론을 같은 개체로 재활용하지 않는다.
2. `advanceEnvironment`: 출현·소멸·억제기/넥서스 포탑 재생·버프 사망 상실·과성장 준비.
3. `environmentTargetable`: 외곽 → 내곽 → 억제기 포탑 → 억제기 순서 확인. 넥서스 포탑은 최소 한 억제기가 파괴되어야 하고, 넥서스는 두 포탑도 파괴되어야 한다.
4. `modifyEnvironmentDamage`: **유효한 공격으로 검증된 후** 실제 피해에 버프/구조물 보호 적용. 스킬에는 `basicAttack=false`로 호출하여 전령/과성장 기본 공격 조건을 보존한다.
5. `onEnvironmentDamage`: 실제 HP 감소 이후 방패 임계값을 한 번만 지급. 주변 수령자가 없으면 나중에 소급 지급하지 않는다.
6. `awardEnvironmentDeath`: 실제 `DEATH` 이후 일반 미니언/챔피언 보상과 별도 처리. 획득/원장/구조물 파괴 기록을 남긴다. 리젠 구조물은 첫 생애의 파괴 보상을 다시 지급하지 않는다.
7. `applySuperMinion`: 실제 웨이브 생성 시 억제기 상태에 따른 압력 적용.

`minion-navigation.ts`는 일반 공격 사거리와 별도로 650 범위의 관측 가능한 지역 목표를 찾아 실제 경로로 접근한다. TOP/BOT 경로에서 넥서스 포탑까지 최단 거리 224인 지점이 있어, 사거리 220의 미니언이 포탑을 지나친 뒤 공격하지 못하는 문제가 있었다. 포탑 좌표나 사거리를 임의 변경하지 않고 지역 추적/목표 소멸 후 레인 복귀로 해결한다. 뒤쪽 레인 경유지는 다시 방문하지 않으며 현재 위치부터 다음 경유지까지 벽 우회 경로를 검사한다. 반환된 실제 경로는 리플레이 상태에도 남는다.

`unit-spatial-index.ts`는 한 이동/공격 스냅샷 안에서만 사용하는 지역 검색 가속기다. 반환 후보는 원본 유닛 순서를 유지하고 정확한 거리 경계를 검사하므로 동률 결정 순서를 바꾸지 않는다. 생사·진영·시야·공격 거리·구조물 잠금 판정은 기존 소비자가 그대로 수행한다. 체크포인트에는 저장하지 않으며 이동 후 공격 판정에는 새 인덱스가 필요하다. 미니언 경로 함수는 기존 전체 목록 입력과 선택적인 지역 후보 목록을 모두 지원하고 양쪽 결과를 동치 검사한다.

`NEXUS_DESTROYED` 이후에만 `FINISHED`와 승자를 설정한다. 이 실험 규칙은 기권이나 시간 초과 자동 승리 기능이 없다. 제한 시간에 넥서스를 파괴하지 못하면 미완료로 남긴다.

단위 시나리오: 생성 시간/둥지 충돌, 독립 유충 3개, 가짜 획득·킬 회복 금지, 실제 처치 기준 재생, 영혼/장로 조건, 버프 사망 상실 및 거리, 구조물 공격 잠금, 넥서스 종료 중복 방지, 백도어 보호, 영구 방패/후반 가치, 과성장 조건, 전령 소모, 억제기 웨이브 압력, 재생 포탑 중복 보상, 잘못된 설정 거부.

미니언 회귀 시나리오는 TOP/BOT 모두에서 공유 Resolver로 포탑의 반격을 받으면서 두 넥서스 포탑과 넥서스를 순서대로 파괴하는 것까지 검사한다. 이 테스트의 높은 체력/공격력은 짧은 시간 안에 경로·종료 불변식을 검사하기 위한 전용 입력이며 실제 밸런스 설정은 아니다.

단위 시나리오가 통과했다는 사실은 실제 5대5 운영 밸런스, 모든 게임의 자연 종료, 기존 커리어 연결 또는 완성된 관전 UI까지 확인했다는 뜻이 아니다. 전체 실행/리플레이/장시간 검사 결과는 상위 구현 기록을 따른다.
