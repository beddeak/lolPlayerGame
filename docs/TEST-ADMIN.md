# 임시 관리자 테스트 패널

로그인 후 세이브를 열고 화면 위의 **임시 관리자 · 테스트 도구** 버튼을 누릅니다. 개발 환경에서는 모든 로그인 계정에 표시되지만 API는 자신의 세이브만 수정할 수 있습니다.

## 선수 수정

- 해당 세이브의 소속 선수, 다른 구단 선수, FA 선수를 선택할 수 있습니다.
- 현재 기본 능력치 8개: 0~119. 폼·컨디션·감독 신뢰: 0~100.
- 원본 PlayerCard, 개발 시드, 다른 세이브에는 반영되지 않습니다.
- 진행 중인 밴픽이 있으면 먼저 해당 세트를 완료해야 합니다.
- 조회 이후 값이 바뀌었다면 충돌로 거절합니다. 다시 불러와 변경 내용을 확인하세요.

## 이적시장까지 자동 진행

확인란을 체크하고 시작하면 현재 연도 11월 19일까지 남은 경기를 자동 밴픽·시뮬레이션하고 기존 날짜 진행 로직으로 계약·이벤트를 처리합니다. 날짜만 덮어쓰지 않습니다. 이미 해당 날짜를 지났으면 아무것도 변경하지 않습니다.

각 요청은 한 세트 또는 하루를 처리합니다. 중단 버튼은 현재 요청이 끝난 뒤 멈춥니다. 화면을 나가거나 탭을 닫아도 완료된 작업은 저장되며 다음에 이어서 진행할 수 있습니다. 서버 백그라운드 작업은 아닙니다.

감독 경질, 수동 결정 이벤트, 국제대회 등록 등 진행 조건이 충족되지 않으면 멈춥니다. 주간 활동·휴식·세트 피드백을 대신 선택하지 않으므로 선수 상태와 경기 결과, 감독 평가가 실제로 달라집니다. 기존 결과를 되돌리는 기능은 없습니다. 네트워크 오류가 나면 자동 재시도하지 않으므로 다시 불러와 마지막 저장 상태를 확인하세요.

## 비활성화

백엔드 환경 변수 `TEST_ADMIN_ENABLED=false`로 API를 차단할 수 있습니다. 변수가 없으면 개발 환경에서만 활성화되고 `NODE_ENV=production`에서는 기본 비활성화입니다. 임시 기능이므로 공개 배포에서 활성화하지 마세요.

## 검증 명령

- backend: `npm test -- --runInBand`
- backend: `npm run test:e2e:isolated -- test-admin.e2e-spec.ts internationals.e2e-spec.ts`
- frontend: `npm run test:admin`, `npm run lint`, `npm run build`

격리 E2E는 별도 테스트 DB에서 마이그레이션·스키마 검증 후 실행하고 테스트 DB만 제거합니다. 사용자 DB나 기존 세이브를 테스트 대상으로 사용하지 않습니다.
