# First Selection / Fearless / BO 시리즈

세 개념을 분리한다. BO1/3/5는 시리즈 승리 조건, First Selection은 매 세트 진영·픽 순서를 결정하는 단계, Fearless는 같은 시리즈의 이전 세트 픽 사용 제한이다.

## 현재 게임 정책

1세트:

- 정규시즌 및 플레이인: 저장된 시리즈 seed로 50:50 코인토스. 홈팀에 고정하지 않는다.
- LCP 정규 단계: 선발 중 Mechanics + GameSense가 높은 2명으로 간단한 2v2 쇼다운. 점수는 평균 `(Mechanics × .6 + GameSense × .4) × .9 + 팀 케미 × .1 + [-10,10) 변동`이다. 같은 점수면 코인토스. 선수 선택·점수·승리팀을 저장한다. 이 계산은 게임용 추상화이지 공식 Riot 계산식이 아니다.
- 국내 플레이오프: 현재 단계에서 시리즈 패배가 없는 승자조 진출팀을 우선하고, 같은 조건이면 단계 참가자의 `initialSeed`가 작은 팀을 우선한다. 시드가 없거나 동률이면 코인토스.
- 국제대회: 지역별 1시드를 세계 공통 시드로 비교하지 않는다. 기본 코인토스, MSI 결승은 UF 승리팀 우선이다.
- 2세트 이후: 앞선 세트의 패배팀. 1세트 시드 우선권을 계속 유지하지 않는다.

이 정책은 사용자와 합의한 게임 정책이며 모든 대회의 세부 규정 전체를 재현했다는 의미는 아니다. 국내 리그 일정·대진 포맷은 이번 변경 대상이 아니다.

## 선택과 저장

`match_series.drafts[gameNumber]` JSON에 version 2 상태를 저장한다. 별도 DB 스키마 변경은 없다.

`selection`에는 `firstSelectionTeamId`, `policy`, 두 선택 이력, `blueTeamId/redTeamId`, `firstPickTeamId/secondPickTeamId`가 있다. 첫 팀은 네 옵션 중 하나, 상대는 남은 차원의 두 옵션 중 하나를 선택한다. 선택값은 각 선택을 하는 팀 기준이다.

픽 순서가 확정될 때 blue/red 선수 스냅샷을 실제 진영으로 배치한다. 밴픽 순서는 기존 20턴 snake 순서를 선픽팀 기준으로 매핑한다. 따라서 레드 선픽도 가능하다. 서버가 계산한 턴 순서를 UI가 그대로 사용하며 경기 기록의 Team A/B 식별자는 바꾸지 않는다.

선택권도 턴당 30초다. 서버가 마감 시각을 검증하며 시간 초과 시 AI 선택을 적용한다. AI는 선픽을 우선하고 상대가 픽 순서를 선점했다면 블루를 선택한다. 화면을 닫으면 백그라운드 타이머가 돌아가는 것은 아니지만, 재진입 시 이미 지난 기한은 서버에서 처리한다.

`POST /match-series/:id/drafts/:game/selection`은 `expectedStep: 0|1`, 선택적으로 `choice: BLUE|RED|FIRST_PICK|SECOND_PICK`을 받는다. 소유권·내 차례·타임아웃·중복 단계·완료 여부를 서버에서 검사하고 기존 Career 트랜잭션 잠금을 공유한다. 선택이 끝나기 전에는 일반 밴픽이나 경기 시작을 할 수 없다.

## Fearless

새 BO3/BO5 시리즈에서 활성화한다. **완료된 이전 세트의 PICK만** `unavailable`에 모은다. 같은 Variant는 양 팀 모두 다시 밴/픽할 수 없다. 같은 유형의 B/C Variant는 별도 선택지다. 일반 BAN은 다음 세트로 전달하지 않는다. 5세트 시작에는 40개가 제한되며, 다음 시리즈에서 초기화된다.

81개 가상 Variant 풀을 사용하므로 일반 밴은 양쪽 미선택 포지션에 최소 선택지를 남겨야 한다. 이 기존 보호 규칙을 프론트와 서버 모두 Fearless 제한을 고려해 계산한다.

기존 version 1 밴픽이 시작된 시리즈는 끝날 때까지 기존 규칙을 유지한다. 저장된 픽·결과를 다시 쓰지 않는다. 다음 새 시리즈부터 새 규칙을 적용한다. 기존 선수 기본 능력치·역할·유형 숙련도 데이터는 변경하지 않았으며, 문서 예시의 Variant별 개인 숙련도를 임의 생성하지 않았다.
