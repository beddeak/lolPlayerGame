| 5 | 이전 세이브/세션 응답이 현재 화면을 덮음 | 세션·선택 세이브별 요청 식별, 오래된 응답·오류 폐기 |

| 7 | 이미 떠난 선수의 미뤄둔 재계약 답변이 진행 차단 | 지연 답변도 최신 소속/협상 유효성 검사 후 무효 협상과 이벤트 정리 |
| 8 | 공용 선수/카드/테마/세트효과 생성 API 무인증 | JWT + 명시된 관리자 계정만 허용, 기본값은 모두 거부. GET/seed 유지 |

관리자 설정은 [공용 데이터 관리 권한](CATALOG-ADMIN.md)을 참고한다. 실제 `.env`에 관리자 ID를
임의로 지정하지 않았다. 기본 선수 데이터와 기존 커리어 데이터도 변경하지 않았다.

정규리그·그룹·스위스 순위는 기존 승수 계산을 유지한다. 단독 시리즈 API도 유지하며,
리그 소속 시리즈만 정상 리그 경로로 진행한다. 이미 완료된 fixture 재호출은 추가 경기를 만들지 않는다.

## 1번에 남은 결정

로드맵은 시즌 중 긴급 보강을 허용할 여지는 있지만, 구체적인 주전 부족 처리 규칙은 정하지 않았다.
긴급 FA만 허용하면 FA가 없거나 거절하거나 AI 팀의 주전이 부족할 때는 진행을 보장하지 못한다.

선수 부족 팀을 부전패 처리하는 방안을 사용자에게 확인 중이다. 양팀 모두 부족하면 무효 경기와
양팀 탈락/진출 자격 처리까지 정해야 한다. 토너먼트에서 단순히 승자를 null로 바꾸면 다음 대진이
다시 막히므로 이 부분을 임의로 구현하지 않았다. 강제 재계약이나 가짜 선수·경기 기록도 만들지 않았다.

따라서 1번은 여전히 미해결이며, 이번 수정만으로 모든 진행 중단 가능성이 제거된 것은 아니다.
