# POG / POM과 경기 결과 화면

## 수상 규칙

- POG: **해당 세트 승리 팀**의 최고 평점 선수. 동점은 킬+어시스트, 적은 데스, 작은 CareerPlayer ID 순으로 결정한다.
- POM: **완료된 시리즈 승리 팀**의 전체 세트 누적 평점이 가장 높은 선수. 승리 팀이 패배한 세트도 합산한다. 동점은 POG 횟수, 누적 킬+어시스트, 적은 누적 데스, 작은 CareerPlayer ID 순이다.
- 교체 출전은 실제 출전 세트만 합산한다. 한 세트의 높은 평균만으로 전체 시리즈 기여도를 대체하지 않는다.
- 미완료 시리즈 또는 유효한 기록이 없는 경우 POM은 `null`이다.

`backend/src/matches/match-awards.ts`가 저장된 경기 스냅샷에서 수상을 계산한다. 경기 응답은 `pog`, 시리즈 응답은 `pom`을 포함한다. 국내·국제대회는 같은 경기/시리즈 서비스를 사용한다. 프론트엔드는 전체 선수 중에서 별도로 MVP를 재선정하지 않는다.

## 저장 및 호환성

- 수상 컬럼이나 마이그레이션 없이 응답 생성 시 계산한다. 기존 저장 경기에도 같은 규칙이 적용된다.
- 시드 재실행, 세이브 재생성, 개발 DB 초기화가 필요하지 않다.
- 구버전 서버에서 수상 필드가 누락되면 프론트엔드는 기록 없음으로 표시한다. 임의의 수상자를 만들어 표시하지 않는다.

## 결과 화면

`frontend/src/QuickSimReport.tsx`는 국내 Quick Sim 결과 모달이다. 시리즈 점수, POM 카드와 통합 기록, 세트별 POG, 양 구단의 출전 선수 상태 변화를 표시한다. 국제대회 진행 패널에 이 모달을 연결하는 작업은 포함하지 않는다.

- 폼/컨디션: 선수별 첫 출전 전 → 마지막 출전 후의 저장값. 세트 사이 피드백 변화도 포함한다.
- 현재 선수단의 실시간 상태로 과거 경기 변화를 추정하지 않는다. 값이 없는 구버전 기록은 `—`로 표시한다.
- 미출전 후보는 제외하고, 교체 출전자는 자신의 출전 구간만 표시한다.
- 기존 완성형 카드 이미지는 `PlayerCardArtwork`를 재사용한다. 일반 선수는 사진 또는 이니셜 카드로 표시하며, 이미지 로딩 실패 시에도 대체 카드가 나온다.
- 네이티브 `dialog`로 포커스를 관리하고 Esc/닫기 버튼/배경 클릭을 지원한다. 모션 감소 설정에서는 카드 효과를 끈다.

## 다크 테마

`frontend/src/ModernTheme.css`를 기능별 CSS 뒤에 불러온다. `body.modern-dark` 범위에서 공통 색상 토큰과 기존 화면의 밝은 배경을 덮어쓴다. 원본 선수 이미지와 구단 로고에는 반전 필터를 사용하지 않는다. 모달 레이아웃은 `QuickSimReport.css`에서 관리한다.

## 검증

- 수상 단위 테스트: 패배 팀 최고 평점, 전체 세트 합산, BO1/BO5, 교체 출전, 동점 규칙, 잘못된 스냅샷, 원본 불변성.
- 격리 MySQL/API 테스트: 저장 후 다시 조회한 수상 정보, POG 승리 팀 제한, POM 누적 평점, 국제대회 회귀 검사.
- 프론트엔드: `npm run test:match-report`로 실제 결과 컴포넌트, 카드, 상태 집계, 모달 이벤트, 기본 텍스트 대비를 검사한다. 기존 화면 검사와 lint/build도 수행한다.
- 자동화된 컴포넌트 검사는 브라우저 레이아웃 검사가 아니다. 이번 작업 환경에는 연결된 브라우저가 없어 실화면 캡처 검증은 수행하지 못했다.
