# 국내 리그 대진표 표시

시즌 화면은 ROUND_ROBIN/GROUP/SWISS에서 순위표, PLAY_IN/SINGLE_ELIMINATION/DOUBLE_ELIMINATION/GAUNTLET에서 대진표를 표시한다. `현재 단계`는 경기 진행에 맞춰 자동으로 따라가며, 개별 단계 버튼을 누르면 이전 순위·대진을 다시 볼 수 있다. 탐색 자체는 경기나 일정을 변경하지 않는다.

기존 단계 응답에 읽기 전용 `bracket`을 추가했다. 노드는 경기 번호·라운드·승자조/패자조/최종전·BO 형식·실제 fixture ID·양 팀 슬롯을 담는다. 슬롯은 참가팀 ID와 이전 경기의 승자/패자 출처를 별도로 보관한다.

- 고정 대진(DOUBLE_SIX/HYBRID_SIX/DOUBLE_FOUR/CBLOL_PLAY_IN)은 스케줄러와 같은 `regionalBracket` 함수를 호출한다. 미정 진출팀도 `N경기 승자/패자`로 표시한다.
- GAUNTLET은 상위 시드 부전승과 이전 라운드 승자를 연결한다.
- 기존 결과별 재시딩 방식은 실제로 생성된 경기만 연결하고, 다음 대진은 결과 후 확정된다고 안내한다. 프론트에서 임의로 미래 대진을 추측하지 않는다.
- 승자 이동은 실선, 패자 이동은 점선. 실제 구단 로고·스코어·일정·승리 표시를 사용하고 내 구단은 금색으로 강조한다.
- 작은 화면은 대진표 영역만 가로 스크롤한다. 미래 경기에 가짜 날짜·스코어를 넣지 않는다.

중요: 이번 작업은 **표시 변경**이다. 현재 LCK의 일부 플레이인·더블 엘리미네이션 엔진은 첨부된 2025 공식 이미지와 다른 단순/재시딩 방식이다. 이미지의 전체 고정 경로를 그대로 재현하려면 해당 대회 생성 규칙을 별도로 변경해야 한다. 이번에는 존재하지 않는 승자전·패자전을 UI에 만들어 넣지 않았다.

DB 스키마·세이브·경기 규칙 변경 없음. 기존 경기/단계 데이터를 조회할 때 대진표를 계산하므로 새 게임을 만들 필요 없다. 프론트와 백엔드를 모두 업데이트해야 한다.

검증: 고정 대진 엔진과 모든 슬롯/출처 비교, 여러 승패 결과 패턴, 혼합 BO3/BO5, 킹오브더힐, 재시딩 패자 경로, 플레이인, 원본 불변성. 프론트 `test:bracket`은 컴포넌트 렌더 검사, `test:calendar`는 단계별 표시·탐색 검사이며 실제 브라우저 시각 검사는 별도다.
