# 내 구단 중심 일정 진행

## 화면

- 시즌 메인 경기 카드와 우측 경기 일정에는 감독 구단의 경기만 표시한다. 국내·국제대회 중 먼저 예정된 내 경기가 메인 카드에 표시된다.
- 경기 카드 바로 아래 `다음 주요 일정까지 진행`으로 날짜와 AI 경기를 함께 처리한다.
- 내 경기, 미해결 중요 결정, 미사용 주간 스크림/휴식, 시즌 구간 및 이적시장 경계에서 멈춘다. 내 경기를 자동으로 시뮬레이션하지 않는다.
- 주간 활동 선택은 구단 화면의 기존 훈련 패널에서 진행한다. 하루·3일·7일 수동 진행은 상단 `날짜 직접 조절` 안에 남겨둔다.
- 캘린더 아래 `다른 팀 경기 내역`에서 국내/국제 경기 결과를 최신순으로 확인한다. 리그 필터와 20개 단위 페이지를 제공한다.
- 국제대회 대진에서도 AI 경기는 수동 처리 버튼 대신 자동 진행 안내를 표시한다. 내 구단이 참가하지 않은 대회는 기본 접힘 상태다.

## API 및 저장

기존 `POST /careers/:id/simulations/fast`에 선택적 `focusManagedTeam: true`를 추가했다. 생략하면 기존 FAST SIM 동작을 유지한다.

- 클라이언트는 요청당 3일 / 최대 5시리즈로 나누어 실행하며, 목표 날짜 또는 처리량 상한에 도착하면 다음 요청을 이어간다. 한 번 누르면 최대 30요청까지 처리한다.
- 국내 AI 경기는 기존 FAST SIM, 국제 AI 경기는 기존 국제대회 시뮬레이터를 재사용한다. 기존 날짜별 폼·계약·이벤트·시즌 처리와 감독 권한 검사를 유지한다.
- `WEEKLY_ACTIVITY` 정지 사유와 선택적 `simulatedInternationalFixtures` 결과 식별자를 응답에 추가했다.
- 중단은 진행 중인 요청이 저장된 후 적용된다. 서버 요청을 강제로 취소하거나 이미 저장된 경기를 되돌리지 않는다.
- 중복 클릭, 이전 세이브/세션의 늦은 응답을 차단한다. 중간 오류 시 최신 데이터를 다시 조회하며 변경 요청을 자동 재전송하지 않는다.
- 경기 내역은 저장된 리그·국제대회 결과에서 읽는다. 새로고침 후에도 유지되며 새 DB 테이블이나 마이그레이션은 필요 없다.
- 국제대회 개막 조건, 실제 참가팀 부족, 계약 결정, 로스터 등록을 건너뛰지 않는다. 수동 날짜 조절에는 기존 규칙을 유지한다.

## 검증

- 백엔드 단위 검사 및 시즌 캘린더/국제대회 MySQL 통합 검사.
- 프론트엔드 전체 회귀 스크립트: 자동 이어가기, 중복 클릭, 중단, 세이브 전환, 중간 오류, 내 경기 우선 표시, 다른 구단 결과 표시, 국제 AI 경기 읽기 전용 처리 포함.
- 프론트엔드 lint/빌드 및 백엔드 빌드.
- MySQL 검사는 자동 생성·정리되는 격리 DB에서만 실행한다. 개발 DB와 사용자 세이브는 변경하지 않는다.
- 브라우저 연결을 사용할 수 없어 실제 브라우저 레이아웃 및 클릭 검증은 미실시. 화면 검사는 컴포넌트 핸들러와 SSR 기준이다.
